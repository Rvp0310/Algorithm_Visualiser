# Algorithm Visualizer

An interactive algorithm visualizer built with Next.js, React, MUI, etc.  
It provides step-by-step visual animations to help understand how different algorithms operate internally, using a clean themed interface.

## Features

- Sidebars with categorized algorithm list and controls
- General control panel (speed, generate input, replay)
- Algorithm-specific control panel that appears dynamically
- Dynamic content area that loads the correct visualization component

## Tech Stack

- Next.js  
- React  
- Material UI  
- TypeScript
