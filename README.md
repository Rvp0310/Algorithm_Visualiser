# Algorithm Visualizer

An interactive algorithm visualizer built with Next.js, React, Tailwind, MUI, and Redux Toolkit.  
It provides step-by-step visual animations to help understand how different algorithms operate internally, using a clean dark-blue themed interface.

## Features

- Collapsible sidebar with categorized algorithm list
- Global state management using Redux Toolkit
- General control panel (speed, generate input, play, pause, next step, reset)
- Algorithm-specific control panel that appears dynamically
- Dynamic content area that loads the correct visualization component
- Modern dark UI with smooth interactions

## Tech Stack

- Next.js  
- React  
- Redux Toolkit  
- Tailwind CSS  
- Material UI  
- TypeScript
